# Source Dossiers

이 폴더는 Source별 evidence appendix다. 상위 흐름은 [../README.md](../README.md)에서 시작하고, Source 판정 요약은 [../02_source-layer.md](../02_source-layer.md)에 있다.

## Dossier Contract

각 dossier는 아래 질문에 답해야 한다.

| 질문 | 기록 위치 |
|---|---|
| 어떤 AccessOption을 선택하거나 거절했는가 | `1. Access Option Decision` |
| 실제 raw/mock artifact가 어디 있는가 | `2. Raw Snapshot Evidence` |
| 시간 key가 무엇이고 어떤 의미인가 | `3. Time Key Verification` |
| 공간 key가 무엇이고 어떤 native grain인가 | `4. Space Key Verification` |
| PoC 기준에서 확인했는가 | `5. PoC Coverage` |
| 최종적으로 REAL/MOCK/EXCLUDE 중 무엇인가 | `6. Final Decision` |

## Machine Counterpart

대부분의 dossier는 `data/reference/source_dossiers/SOURCE_*.json`에도 대응 record가 있다. `SOURCE_CRITICAL_INFRASTRUCTURE_DETAIL`과 `SOURCE_SETTLEMENT_BOUNDARIES`는 active evidence가 없는 exclusion memo 성격이므로 markdown에서 제외 사유를 관리하고, authoritative status는 `data/reference/source_inventory.json`을 따른다.

# Reference Data

코드표, 매핑표, canonical Source 인벤토리, Source별 수집 option, Source Dossier를 저장한다.

- `source_inventory.json` — canonical machine-readable Source 인벤토리 (29개 entry, `SOURCE_*` ID).
- `source_access_options.json` — Source별 endpoint/layer/행정 단위/시간 조건 후보 (48개 entry, `ACCESS_*` ID).
- `source_dossiers/` — sample 확인 후 채우는 source별 time/space key 및 PoC coverage 검증 결과.

기타 참조 데이터 예:

- 법정동코드
- 시군구코드
- KMA nx/ny 격자 매핑
- source별 코드 매핑
- segment type code

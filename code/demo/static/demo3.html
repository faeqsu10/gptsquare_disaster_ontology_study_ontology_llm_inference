어떻게 동작하나요? — 4단계 흐름

질문을 입력하면 아래 4단계가 순서대로 펼쳐집니다.

  1. ① 자연어 질문 "EMD_여수_상암동 위험도 알려줘"
  2. →
  3. ② LLM이 TypeQL 생성 match $s isa segment, has segment-id "..."; select $sn, $st, $sp;
  4. →
  5. ③ TypeDB 실행 → JSON [{ "sn":"여수 상암동", "st":"PriorityPreWatering", ... }]
  6. →
  7. ④ JSON → 자연어 답변 "여수 상암동의 산불 위험도는 '매우높음'이며..."

임계값 (threshold-set) — 그래프에 적재된 버전

버튼으로 그래프에 저장된 버전을 즉시 비교하거나, 슬라이더로 임의 값을 시험한 뒤 새 버전으로 저장할 수 있습니다.

버전 로딩 중… 슬라이더 편집 중 (저장 안 됨)
일반 감시 검토 우선 즉시
low0.20
mid_low0.40
mid_high0.60
high0.80
📥 그래프에 저장될 TypeQL 슬라이더를 움직이면 아래 숫자가 함께 바뀝니다 
insert
  $t isa threshold-set,
    has threshold-set-id "TS_S_PRIORITY_V1",
    has metric-name      "S_priority_to_state",
    has config-version   "v1",
    has th-low      0.20,
    has th-mid-low  0.40,
    has th-mid-high 0.60,
    has th-high     0.80;

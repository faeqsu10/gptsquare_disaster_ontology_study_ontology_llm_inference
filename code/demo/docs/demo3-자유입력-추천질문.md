# 시연 ③ — 자유 입력 추천 질문 (발표 직전 참조)

> 시연 ③의 preset 칩 3개(`EMD_여수_상암동 위험도 알려줘`, `MOCK 상태인 source 모두 알려줘`, `1990년 1월 광주 동구 위험도?`) 외에 **직접 타이핑해 테스트할 만한 자연어 질문 모음**. 그래프에 실제 적재된 데이터(5 segment, ~29 source, threshold-set v1/v2, weight-set v1)를 기반.

> ⚠️ Gemini는 매번 약간씩 다른 TypeQL을 만들 수 있어 같은 질문도 시도마다 결과가 달라질 수 있다. 발표 직전 3~4개는 미리 돌려보고 안정적인 것을 골라두자.

---

## 🟢 안전 — LLM이 거의 확실히 잘 처리할 질문

그래프에 데이터가 명확히 있고, 골든 패턴과 매우 유사하다.

### 다른 segment 위험도 조회
- `EMD_장흥_유치면 위험도 알려줘`
- `EMD_무안_운남면 상태 어때?`
- `광주 북구 001 어떤 상황이야?`

### 행정구역 필터
- `전남에 있는 segment 모두 알려줘`
- `여수 지역 segment 알려줘`

### 격상/조정 사유 (state-override-reason 활용)
- `장흥 유치면이 왜 작업 불가야?` (hazard_gate → ⛔ 안전 게이트)
- `EMD_나주_봉황면 격상 사유 있어?` (없으면 자연스럽게 "없다"고 답함)

### attribute 단순 조회
- `여수 상암동 풍속이 얼마야?`
- `EMD_여수_상암동 거주 인구는?`
- `EMD_광주_북구_001의 산림 거리는?`

---

## 🟡 도전적 — 분석/집계 질문 (재시도 발생할 수 있음)

LLM이 한 번에 실패해도 시연 ③의 **자가 수정(🔁) 동선**을 자연스럽게 시연 가능. 실패해도 메시지가 살아있다.

- `5개 segment 중 위험도 가장 높은 곳은?`
- `거주 인구가 가장 많은 segment 어디야?`
- `풍속이 가장 빠른 segment 알려줘`
- `장흥 유치면과 광주 북구 001 중 어디가 더 위험해?`
- `v2 임계값과 v1 임계값 차이 알려줘`

---

## 🔴 거절 시연용 — 환각 방지 메시지가 강력

의도적으로 데이터에 없는 것을 물어 **"답을 만들지 않는다(거절)"**를 보여준다. **발표 하이라이트로 추천**.

### 존재하지 않는 segment
- `EMD_서울_강남구 위험도 알려줘`
- `EMD_부산_해운대구 상태 알려줘`
- `제주도 segment 있어?`

### 미래/과거 시점
- `2030년 5월 광주 위험도?`
- `100년 전 산불 데이터 있어?`

### attribute에 없는 정보 (개인정보 등)
- `EMD_여수_상암동에 사는 사람 이름은?`
- `여수 상암동 산불 발생 횟수는?` (history 미적재)

→ 모두 `"…해당 시점·조건의 데이터가 그래프에 존재하지 않습니다. 그래서 답을 만들지 않습니다 (환각 방지)."` 로 응답

---

## 🟣 source/policy 관련 — 메타 데이터 조회

그래프에 정책(threshold/weight)·관측 출처(source)가 **노드로 있다**는 메시지를 한 번 더 강화.

- `전체 source는 몇 개야?`
- `MOCK source 이름 알려줘`
- `현재 v1 가중치 알려줘`
- `최근 추론은 언제 돌렸어?`

---

## 발표 진행 추천 시나리오 (1분, 3박자)

```
1) "EMD_장흥_유치면 위험도 알려줘"
     → 다른 동네도 잘 됨, 1분 만에 메시지 확보

2) "거주 인구가 가장 많은 segment 어디야?"
     → 자가 수정 🔁 동선 시연 가능성

3) "EMD_부산_해운대구 위험도 알려줘"
     → 환각 방지 거절 (하이라이트)
```

청중 흐름:
- "와 이것도 되네?" (자연어 인터페이스)
- "오 이건 재시도하네?" (자가 수정)
- "오 이건 거절하네?" (환각 방지)

시연 ③의 핵심 메시지 3가지가 한 번에 전달됨.

## 부록 — 그래프에 실제 적재된 데이터 요약

| 종류 | 식별자 / 값 |
|------|------------|
| segment (5건) | `EMD_여수_상암동`, `EMD_나주_봉황면`, `EMD_장흥_유치면`, `EMD_광주_북구_001`, `EMD_무안_운남면` |
| segment attribute | `state`, `s-priority`, `state-override-reason`, `alert-level`, `risk-grade`, `safety-class`, `residential-population`, `forest-distance-m`, `wind-speed`, `segment-name`, `admin-region` |
| source (~29건) | REAL/MOCK 두 종류 (시연 ③ preset 칩 2번째와 동일 패턴) |
| threshold-set | `v1`(0.20/0.40/0.60/0.80), `v2`(0.15/0.30/0.50/0.70), `v3`(시연 ②에서 추가 시) |
| weight-set | `v1` (formula-id=`S_priority`, w-official/exposure/spread/action/time) |
| run-context | 추론 시점 메타 (reference-time, status=completed) |

이 데이터 범위 안에서 질문하면 거의 잘 답한다. 벗어나면 "거절"이 발생하고, 그건 그것대로 발표용 메시지가 된다.
